# pytorch-bmi-model
Simulation of a BMI center-out reaching task using a recurrent neural network (RNN). The RNN can control either an arm model or a cursor.

## Steps
1. Create the conda environment using `environment.yml` and activate it.
2. Open file `sim_point_mass_arm_with_feedback.py` and set parameters to your liking (or leave everything to their default). Perhaps change the string for `DATADIR` and `RESULTDIR`, right after the comment `MAIN CODE`. 
3. Run `run_point_mass_arm_with_feedback.sh`. This will generate models of manual reaching (put into `data` folder). To test this part, I'd suggest to set `N_SEEDS=1` in the `.sh` file. You can also run `sim_point_mass_arm_with_feedback.py` directly when testing a single seed.
4. Open file `sim_clda.py`. Change the string in `MANUAL_DATADIR` so that the program loads the pre-trained model generated by file `sim_point_mass_arm_with_feedback.py`. Change `DATADIR` and `RESULTDIR` if needed.
5. Run `run_clda.sh`. You can select the number of seeds (`N_SEEDS`) and the values of CLDA to test.

## Notes
1. If you use Pycharm, running the bash scripts (files ending with `.sh`) can be done directly in the IDE.
